# Changelog — August 22, 2026

## Overview
Resolved critical guest quiz launch blockers, added database transaction safety on grading and quiz creation, pushed additive schema columns for Spaced Repetition System (SRS) & Conceptual Drills, and created the 8 Cognitive Archetype Conceptual Reasoning authoring workflow.

---

## Tier 1: Guest Quiz Launcher & Grading Flow (Critical Fixes)
- **Resolved 401 Unauthorized Blockers**:
  - Updated `platform/app/api/attempts/route.ts` and `platform/app/api/attempts/[attemptId]/submit/route.ts` to allow guest users to create and submit quiz attempts using the default archive user UUID (`00000000-0000-0000-0000-000000000001`) when unauthenticated.
- **Fixed Stuck "Starting session..." Button**:
  - Wrapped `handleStart` in `platform/app/quizzes/[setId]/quiz-detail.tsx` with robust error handling and `setStarting(false)` resets on failure/network errors.
- **Guest Access in Taking & Results**:
  - Updated `platform/lib/attempts.ts` (`getAttemptForTaking`) and `platform/lib/grading.ts` (`getAttemptResults`) to allow guests to retrieve and view test attempts without requiring an active OAuth session.

---

## Tier 2: Data Integrity & Edge Runtime Safety
- **Atomic Grading Transactions**:
  - Wrapped the `DELETE` old answers + `INSERT` new answers + `UPDATE` attempt score flow in `platform/lib/grading.ts` inside `db.transaction()` to prevent partial answer loss on connection drops.
- **Edge-Safe WebSocket Constructor**:
  - Made the `ws` package import in `platform/lib/db/client.ts` conditional (`typeof WebSocket === "undefined"`), preventing runtime packaging crashes if routes use the Edge runtime.

---

## Tier 3: Schema Extension & Live Database Backfill (SRS Foundation)
- **Additive Drizzle Schema Update**:
  - Added `tier` (`diagnostic`, `review`, `drill`, `simulation`, `conceptual_drill`) and `topicCode` (e.g. `MATH-01`, `ELEC-03`, `EST-10`) to `question_sets`.
  - Added `archetype` (`standard`, `scaling`, `boundary`, `phase`, `fault`, `material`, `info`, `theorem`, `trap`), `microCluster`, and `isAnchor` to `questions`.
  - Added `user_topic_srs` table for tracking user memory stability, retrievability, and review due dates per topic with $0 compute overhead.
- **Neon Cloud PostgreSQL Migration**:
  - Pushed all schema changes to live Neon PostgreSQL via `npx drizzle-kit push`.
- **Live Database Backfill**:
  - Executed idempotent backfill script via `platform/scripts/verify.ts`, successfully normalizing and updating `tier` and `topicCode` across all 190 live question sets (5,428 questions).
