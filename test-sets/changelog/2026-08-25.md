### 12. Test-Set Topic Tagging, Sorting & Subject Filtering Fix
- **Root Cause Resolution:**
  - `getLibraryQuizzes` in `platform/lib/quizzes.ts` previously omitted `topicCode` and `tier` in its return payload, causing `library-view.tsx` to rely on heuristic string matching where topic tags (e.g. "Dc Circuits", "Test And Measurement") produced false positives (matching "EST" in "Test") or fell back to `MATH`.
  - Filter logic used strict `subj.code !== selectedSubject` mismatching key `"ELECS"` vs code `"ELEC"`.
- **Comprehensive Database Sync:**
  - Populated canonical `topic_code` (`MATH-01` to `MATH-13`, `ELEC-01` to `ELEC-15`, `GEAS-01` to `GEAS-12`, `EST-01` to `EST-10`) across all 201 syllabus question sets in Neon PostgreSQL.
- **Canonical Topic Catalog & Taxonomy Inferencer (`platform/lib/constants.ts`):**
  - Added `TOPIC_CATALOG` with full 50-topic metadata, domain bindings, and sequence indices.
  - Implemented `inferSubjectAndTopicCode()` to reliably resolve domain, code, and topic number across `topicCode`, `title`, and `subjectTag`.
- **Sequential Syllabus Sorting & Tier Ordering (`platform/app/quizzes/library-view.tsx`):**
  - Grouped topics now sort sequentially: `MATH (01–13)` $\to$ `ELECS (01–15)` $\to$ `GEAS (01–12)` $\to$ `EST (01–10)`.
  - Quiz cards within each topic accordion sort by pedagogical tier: `Diagnostic (30Q)` $\to$ `Review (25Q)` $\to$ `Drill (10Q)` $\to$ `Simulation (50Q)`.
