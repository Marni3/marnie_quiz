  - `MATH-08`: Solid Mensuration (separated from Solid Geometry)
  - `MATH-09`: Analytic Geometry
  - `MATH-10`: Differential Calculus
  - `MATH-11`: Integral Calculus

  - `MATH-13`: Advanced Engineering Mathematics (renumbered from `MATH ADV`)

### 3. Skill Tree Visual Enhancements (`skill-tree-map.tsx`)
- **Fractional SVG Progress Arcs:** Replaced static full circles with dynamic SVG `strokeDasharray` fractional arcs reflecting exact set completion ratios ($\text{CompletedSets}/\text{TotalSets}$).
- **Data-Driven Chromatic Mastery Rings:** Standardized performance color-coding:
  - 🟢 Fresh / High Accuracy ($R \ge 0.85$, Score $\ge 80\%$)
  - 🟡 Review Due ($R < 0.85$)
  - 🔴 Struggling ($R < 0.60$ or Score $< 70\%$)
  - ⚪ Unstudied (Neutral border)
- **Compact Vertical Rhythm:** Streamlined vertical stepping stone spacing for optimal readability without excessive scrolling.

### 4. Subtopic Range Grouping UI (`library-view.tsx`)
- **Interactive Subtopic Range Filters:** Added dynamic filter chips inside topic accordions (e.g., `01-01 to 01-07: Foundations` vs `01-08 to 01-19: Word Problems`) enabling quick targeted drills.

### 5. Per-Subject Daily Recovery Refresher Drills
- **API & UI Support:** Upgraded `/api/srs/daily-drill` with optional `?domain=MATH|ELECS|GEAS|EST` parameter.
- **1-Click Quick Refresher Chips:** Added `📘 Math`, `📙 Elecs`, `📗 GEAS`, and `📕 EST` 1-click drill launcher chips directly to the Daily Retention Radar banner in `/quizzes`.

### 6. Google OAuth 2.0 Integration
- **NextAuth Google Provider:** Configured `GoogleProvider` in `platform/lib/auth.ts` with support for `AUTH_GOOGLE_ID`/`AUTH_GOOGLE_SECRET` and `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET`.
- **Neon User Provisioning:** Configured automatic user upsert into Neon PostgreSQL `users` table on Google OAuth sign-in.
- **Login UI:** Updated `/login` with branded "Continue with Google" button alongside the developer/guest sign-in form.

### 7. Instant Bulk Neon DB Synchronization
