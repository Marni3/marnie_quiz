Properties of Relations 
1. Reflexive 
If ordered pair (a, a) is an element of the set of 
Relation for every a that is an element of set A. 
Example: 
A = {1, 2, 3} 
R = {(1, 1), (2, 2), (2, 3), (3, 3)} → Reflexive 
R = {(1, 1), (2, 1), (2, 3), (3, 3)} → Not reflexive 
 
A relation is reflexive if, we observe that for all 
values a: a R a 
In other words, all values are related to 
themselves. 
 
2. Irreflexive 
If ordered pair (a, a) is NOT an element of the set 
of Relation for every a that is an element of set A. 
Example: A = {1, 2, 3} 
R = {(1, 3), (2, 1), (2, 3), (3, 1)} → Irreflexive 
R = {(1, 1), (2, 2), (3, 3)} → Not irreflexive 
 
3. Symmetric 
If ordered pair (a, b) and (b, a) are elements of the 
set of Relation for every a and b that is an element 
of set A. 
Example: A = {1, 2, 3} 
R = {(1, 1), (2, 1), (1, 2), (3, 3)} → Symmetric 
R = {(1, 1), (2, 1), (2, 3), (3, 3)} → Not symmetric 
 
4. Antisymmetric 
If ordered pair (a, b) and (b, a) are elements of the 
set of Relation given that a = b. 
Example: A = {1, 2, 3} 
R = {(1, 1), (2, 1), (1, 2), (3, 3)} → Not 
antisymmetric 
R = {(1, 1), (2, 1), (2, 3), (3, 3)} →antisymmetric 
 
Note: Antisymmetric is not the same as “not 
symmetric”. 
 
5. Transitive 
If ordered pair (a, b) and (b, a) are elements of the 
set of Relation, then (a, c) is an element of the set 
of Relation.  
Example: A = {1, 2, 3} 
R = {(1, 1), (2, 1), (1, 2)} → Transitive 
R = {(2, 2), (3, 1), (1, 3)} → Not transitive

Types of Functions 
Functions can either be one to one (injective), 
onto (surjective) or bijective. 
 
Injective Functions 
These are functions in which every element in 
the domain maps into a unique elements in the 
codomain. 
One-to-One Functions

Surjective Functions
