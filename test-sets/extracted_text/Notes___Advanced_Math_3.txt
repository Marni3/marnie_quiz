same order/size/dimensions, the sum 
of A and B, denoted by A + B, is the 
matrix for which each of its elements 
is the sum of the corresponding

4.  Multiplication of Matrices 
 
If you have two matrices, A and B, 
the product AB is defined when the 
number of columns of A is equal to 
the number of rows of B. Supposed 
that A is a matrix of order m x p 
and B is a matrix of order p x n, 
then the product of A and B, 
denoted by AB, is the n x n matrix 
for which the element in the ith 
row and the jth column is the sum 
of the products formed by 
multiplying each elements in the 
ith row of A by the corresponding 
element in the jth column of B. 
  
Listed below are some rules in the 
multiplication of matrices: 
• Matrix multiplication is not 
commutative 
• Matrix multiplication is associative 
and distributive with respect to 
addition of matrices 
• AB = 0 does not necessarily mean 
that BA = 0 or that A = 0 or B = 0
