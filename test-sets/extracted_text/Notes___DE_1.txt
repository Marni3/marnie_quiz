Differential Equations

has at least one arbitrary 
constant. 
 
 Example:  x3 – 3y = C 
     
 where: C = arbitrary constant 
 
2. Particular solution – the 
solution that has no arbitrary 
constant. 
 
 Example:  2xy + y2 – 2 = 0  
 
 
 
  Introduction 
A differential equation is an equation 
that contains one or more terms 
involving derivatives of one variable (the 
dependent variable, y) with respect to 
another variable (the independent 
variable, x). In other words, the variable 
is called dependent if a derivative of that 
variable occurs. Usually, differential 
equations are used as models to 
approximate real-world problems.

only ordinary derivatives in the 
equation.
