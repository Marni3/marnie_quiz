# Development Changelog — 2026-08-31

### 1. Robust KaTeX Prose Boundary Guard, Code Span Pills, and Dynamic "Continue Last Module" Fallback
- **KaTeX Inline Delimiter Sanity & Prose Protection (`math-text.tsx`)**:
  - Restrained inline math tokenization to single-line spans (`\$[^\$\n\r]+?\$`) so unmatched `$` delimiters cannot consume multi-line paragraphs.
  - Added prose-boundary heuristic to automatically detect and de-escalate LLM-generated math tokens that inadvertently wrap entire English sentences or markdown styling (`**bold**`).
  - Added inline code span rendering (`` `...` ``) with styled pill containers (`px-1.5 py-0.5 rounded-md bg-[var(--surface2)] font-mono text-xs text-[var(--accent)] font-semibold`) for calculator tricks and keystroke sequences like `` `[\sqrt{}]` ``.
- **Strict Prompt Math Delimiter Directives (`prompts.ts`)**:
  - Updated `BASE_SOCRATIC_PROMPT` with strict rules forbidding the wrapping of plain English sentences, phrases, or markdown inside `$...$` delimiters.
- **Dynamic "Continue Last Module" CTA Bar (`module-reader.tsx`)**:
  - Guaranteed that the post-drill momentum CTA will always display **`[ 📖 Continue Last Module: {CODE} ]`** (with dynamic fallback to the current module's domain code or `EST-01`) instead of the generic "Explore Module Library".
