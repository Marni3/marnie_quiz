# Changelog — 2026-08-18

## Session work

### Standalone study tool (`quiz.html`)

This session produced a self-contained single-file HTML quiz app intended for use while the full Next.js platform is being built. It is **not** part of the main platform codebase — it lives at the repo root as a standalone utility.

**Initial version**
- Drag-and-drop CSV upload via PapaParse, validated against the exact schema defined in `implementation-plan.md` Section 7 (`question`, `choice_a–d`, `correct_answer`, `explanation`, `image_url`, `subject_tag`)
- Row-numbered validation errors on bad files; rejects the whole file on any error
- Timer modes: untimed, per-question countdown, whole-exam countdown (all configurable)
- Quiz-taking screen: question navigator grid (answered / current / flagged states), flag-for-review, prev/next navigation, progress bar
- Grading computed client-side from the CSV's `correct_answer` after submit (note: this is a local study tool, not the platform — server-side grading is a platform concern per Section 4 of the plan)
- Results screen: score %, correct/wrong/skipped/time stats, per-question review with correct answers highlighted, explanations shown
- Review filter tabs: All / Incorrect / Correct / Skipped / Flagged
- MathJax v3 for LaTeX rendering in questions, choices, and explanations (`$...$` inline, `$$...$$` display)
- Retake and Load New CSV actions

**Second revision (same session)**
- Academic theme overhaul: warm cream/parchment light mode (Lora serif, subtle horizontal rule lines, off-white surface palette), deep navy dark mode
- Dark/light toggle in the topbar — persists to `localStorage`
- Smooth screen transitions: CSS keyframe fade-out + slide-up-in between upload, quiz, and results screens
- AI prompt card on the upload screen: collapsible section with a copyable prompt that instructs any AI to generate a correctly-formatted CSV, including exact column rules, LaTeX formatting requirements (inline/display delimiters, no Unicode math), and CSV escaping rules

**Third revision (same session)**
- Color palette overhaul: Anthropic orange (`#d97757` / `#e8895a` on dark, `#c2622a` on light) replaces blue/purple accents throughout. All combinations verified against WCAG AA 4.5:1 minimum for normal text.
- Dark mode background changed from blue-tinted navy (`#111318`) to warm charcoal gray (`#222020`) — avoids halation and is less fatiguing for extended reading sessions, per WCAG dark mode best practices. Surfaces and borders updated to match warm gray palette.
- Dark mode background glow replaced with a faint dot grid (28px spacing, orange-tinted dots at 18% opacity, 60% overall) for subtle visual texture.
- AI prompt rewritten to be topic-agnostic (removed medical framing); works for any subject area. Examples updated to cover multiple disciplines (Chemistry, Law, Economics, Medicine). Subject tag examples updated to title-cased topic names.
- AI prompt: documented `\n` literal token approach for multi-paragraph explanations — the AI writes `\n` as a two-character sequence inside the CSV cell, which the app parses into separate paragraph elements.
- Explanation renderer updated: splits on `\n` literal and renders each segment as a `<p class="explanation-text">` element with proper inter-paragraph spacing.
- Explanation box now has a left accent border (matches `--accent` color) for better visual grouping.
- Badge background colors updated to warm-neutral tones consistent with the new palette.

### Full Platform Implementation (`platform/`) — Phases 0, 1, and 2

Scaffolded and fully built the official full-stack Next.js 15+ board exam review platform in `platform/` according to the master specification in `implementation-plan.md`:

- **Phase 0: Architecture, Schema & Scaffolding**
  - Next.js 15+ App Router, TypeScript, React 19, Tailwind CSS with design tokens.
  - Anthropic orange (`#d97757` / `#e8895a` / `#c2622a`) with WCAG-audited cream light mode & warm charcoal (`#222020`) dark mode, dot grid and paper textures.
  - Complete 7-table Drizzle ORM PostgreSQL schema in `lib/db/schema.ts` (`users`, `folders`, `question_sets`, `questions`, `question_set_items`, `attempts`, `answer_records`).
  - Drizzle migration generated: `0000_smart_longshot.sql`.
  - Neon Serverless PostgreSQL connection pooling with fallback in-memory store for local development resilience.
  - Auth.js v5 with Google OAuth provider, Dev credentials fallback, and JWT session user upsert callback.
  - Route protection middleware in `middleware.ts`.
  - CSV parsing and validation via PapaParse and Zod (`lib/validations/csv.ts`).
  - KaTeX LaTeX math typesetting component (`components/math-text.tsx`) supporting `$..$` inline and `$$..$$` display equations.

- **Phase 1: MVP Core Features**
  - **Login Page (`/login`)**: Google sign in & local dev sign in with theme toggle and branded hero.
  - **Library Hub (`/quizzes`)**: Shared question set cards with subject badges, question counts, uploader avatars, search, and filters.
  - **Upload Page (`/quizzes/upload`)**: Drag-and-drop CSV upload, title, subject tag, row-numbered validation errors, and collapsible AI prompt generator.
  - **Quiz Detail (`/quizzes/[setId]`)**: Metadata preview, timer mode selection (untimed / per-question / whole-exam), feedback mode (instant vs. deferred), and launch button.
  - **Active Quiz Runner (`/attempts/[attemptId]`)**: Progress bar, question stem, LaTeX choices, flag for review, jump navigator grid, timers with auto-advance/submit.
  - **Security Rule Enforcement**: Server never sends `correctChoice` or `explanation` to client during active quiz taking.
  - **Server-Side Grading & Results (`/attempts/[attemptId]/results`)**: Server computes score against DB, saves `answer_records`, displays stats (correct, incorrect, skipped, time), and renders multi-paragraph explanations (`\n` parsed) with LaTeX math.
  - **History Page (`/history`)**: Complete table of user's past attempts with scores, dates, durations, and resume/results actions.

- **Phase 2: Organization, Privacy & Interactive Question Modules**
  - **Folder Management**: In-library folder creation, renaming, deletion, and quiz assignment. Filter library by folder or unfiled.
  - **Privacy Controls**: Shared vs. Private visibility toggle on uploads and edits (`question_sets.visibility`). Private sets are hidden from other users.
  - **Interactive Question Modules**: Attach self-contained HTML/JS visualizations (enforcing 300 KB max limit) or external tool URLs per question.
  - **Sandboxed Rendering**: All modules rendered in `sandbox="allow-scripts"` (no `allow-same-origin`) both inline in results review and in a dedicated full-screen route (`/modules/[questionId]`).

### Wide Dashboard Layout & Static Test-Sets Manifest Generator (`study-app/`)

Upgraded the standalone `study-app` MVP into a wide, Quizlet-inspired dashboard with automatic repository test-sets discovery for Vercel:
- **Build-Time Manifest Crawler (`scripts/generate-manifest.js`)**:
  - Traverses the nested `test-sets/` directory hierarchy (e.g. *Mathematics → Analytic Geometry*, *Advanced Math*, *Trigonometry*, etc.).
  - Extracts formatted quiz titles, relative asset paths, pre-computed question counts, and subject tags.
  - Generates `study-app/manifest.json` and `test-sets/manifest.json`.
  - Added root `package.json` with `"build": "node scripts/generate-manifest.js"` for seamless Vercel automated deployments.
- **Wide Dashboard UI (`study-app/index.html` & `study-app/css/style.css`)**:
  - Replaced the narrow centered view with an expansive 1440px two-column grid.
  - **Main Area (~70%)**: Real-time keyword search across all quiz sets, category filter pills (*All Topics*, *Mathematics*, *Sample*, etc.), and a responsive grid of quiz cards with question counters and direct one-click launcher buttons.
  - **Sidebar Panel (~30%)**: Study session configuration (feedback modes & timer options), compact custom CSV dropzone for drag-and-dropping local files, and collapsible AI prompt generator with one-click copy.
- **Direct Asset Fetching (`study-app/js/home.js`)**:
  - Clicking any indexed quiz card fetches the CSV directly over HTTP and launches the session immediately without manual file selection.
