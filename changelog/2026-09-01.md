# Development Changelog — 2026-09-01

### 1. FSRS Mastery Challenge & Spaced Repetition Pipeline Integration (`main`)
- **Root-Cause Resolution**:
  - Previously, completing a learning module or its paired companion Mastery Challenge only updated `userModuleProgress`. It never synced `userTopicSrs`, causing the Retention Board, Board Readiness Index ($BRI$), and Daily Refresher Drill queues to show "0 topics studied" and "No Upcoming Reviews".
- **Unified Topic SRS Sync (`srs.ts`, `/api/modules/[moduleId]/progress/route.ts`)**:
  - Created `updateTopicSrsDirectly` to automatically update or insert `userTopicSrs` records whenever a module's concept checks or mastery exam is submitted.
  - Computes empirical initial stability ($S_0$) and schedules `nextReviewDue = now + stabilityDays` ($R = 1.0$).
  - Studied topics now immediately appear on the **Spaced Repetition Retention Board** under **Upcoming (1–3 Days)** or **Mastered & Stable**, transitioning to **Due for Review Today** once $R < 85\%$ or `nextReviewDue <= now`.

### 2. AI Tutor Post-Exam Review Engine & Streaming UX Overhaul (`main`)
- **Context Pruning (`results-view.tsx`, `mastery-runner.tsx`)**:
  - Pruned exam review payload from all 25–50 questions down to the **top 10 missed or skipped questions**.
  - Formats problem stems, student choice vs correct choice, short explanations, and exam metrics (`totalMissed`, `score`, `percentage`).
- **Deep Board-Exam Review Prompt (`prompts.ts`)**:
  - Re-engineered `review_exam` system prompt to thoroughly deconstruct each missed item:
    1. **Governing Equation & Concept**: Display KaTeX ($$...$$) from first principles.
    2. **Formal Board Solution**: Step-by-step substitution and algebraic proof.
    3. **Trap Diagnosis**: Root-cause analysis of distractor misconceptions.
    4. **⚡ Calculator Speed Technique**: Keystrokes for Karce KC-S991 / Canon F-789SGA.
  - Raised max output token ceiling to **3,000 tokens**.
- **Deferred KaTeX Streaming UI Pattern (`tutor-view.tsx`)**:
  - Eliminated browser freezes caused by heavy KaTeX re-parsing on every incoming stream chunk.
  - **While Streaming**: Displays an animated status badge `⚡ Generating comprehensive board review... (X.Xs)` with an elapsed second counter and a collapsible `[ ▾ Peek live stream ]` dropdown displaying lightweight monospace raw text with zero KaTeX overhead.
  - **On Stream Completion**: Renders the complete, beautifully typeset KaTeX response in a single smooth 60fps pass.
- **Decoupled Remedial Practice Drill CTA (`chat-message.tsx`)**:
  - Replaced inline JSON clutter with an interactive **`[ ⚡ Launch 5–10Q Remedial Drill ]`** CTA button that dispatches a dedicated request to generate an interactive quiz modal.
